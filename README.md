# TechCompare India — Laptop & Mobile Store Comparison Hub

An interactive single-page web application that brings together **26 leading Indian e-commerce platforms, omnichannel retail chains, official brand stores, and refurbished/buyback portals** to compare stores and search for laptops and smartphones across India in one place.

**Live Demo:** `https://srini-ctrl.github.io/tech-compare-india/`

---

## Key Features

- **Live Multi-Store Product Search:** Enter any laptop or smartphone model (or click quick search presets) to generate direct search links across all 26 Indian stores simultaneously.
- **One-Click Top-4 Store Launcher:** Open your product search across the top 4 Indian electronics retailers (Amazon India, Flipkart, Croma, and Reliance Digital) at once.
- **Side-by-Side Store Comparison Matrix:** Compare up to 4 stores head-to-head across store category, devices sold, delivery and pickup speed, EMI and bank discounts, trade-in/buyback support, and key advantages—with quick comparison presets (*Top Retailers* vs. *Refurbished & Sell Old*).
- **Category & Device Filtering:** Filter stores by category (*Marketplaces*, *Omnichannel Chains*, *Official Brand Stores*, and *Refurbished & Sell Old*) or by device type (*Laptops*, *Mobiles*, or *Both*).
- **Grid & Table View Switcher:** Toggle between visual store cards and a compact directory table.

## Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript** — Zero external frameworks or backend dependencies; runs natively in any modern web browser.
- **Hosted on GitHub Pages** — Static deployment directly from `index.html`.

---

## How to Run Locally or Deploy

1. Download or clone this repository.
2. Open `index.html` directly in any web browser—no build tools or server setup required.
3. To host on **GitHub Pages**, push `index.html` to the root of a public repository and enable **Pages** under **Settings → Pages → Deploy from a branch (`main` / `/root`)**.
